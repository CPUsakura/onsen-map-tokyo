渋谷笹塚温泉 栄湯

Shibuya Sasazuka Onsen Sakaeyu｜渋谷区｜銭湯

浴室と浴槽は、すべて東京都から「メタケイ酸」温泉の認定を受けた水を使っています。風呂は3つ、うち1つは水風呂です。「コンフォートサウナ」（有料）は、入浴料とタオル込みで1,100円（小学生以下は不可）。ロビーにマッサージチェアがあり、コインランドリーも併設しています。

泉質について

メタケイ酸泉
無色透明、または淡褐色の温泉で、美肌が期待できるとされています。井戸水を調べて、メタケイ酸泉だと分かる例もあります。

◇営業時間・定休日・料金・設備・温泉の現況は変更されることがあるため、お出かけ前に各施設の公式サイトで確認してください。

◇東京都内のすべての温泉を網羅しているわけではありません。

◇島しょ部の海辺の温泉は、潮位や天候で入れないことがあります。島に行く前に、各島の観光協会で確認してください。

◇温泉の泉質により体調に不安がある方は、入浴前に医師へ相談してください。
